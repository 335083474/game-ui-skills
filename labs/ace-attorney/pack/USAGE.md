# Use this reference package

Provide the complete `ace-attorney-ui` directory to your AI. Use the rules and witness art to compose original screens. `assets/components/index.html` is an editable primitive page, not a finished case interface.

Suggested request:

> Use the `ace-attorney-ui` reference package to build three connected responsive Web screens for an original courtroom mystery: an evidence file, cross-examination, and episode selection. Reuse the fictional witness portrait, keep `PRESS` and `PRESENT` as different actions, and implement evidence selection, statement selection, and chapter navigation with keyboard and pointer input. Keep the runnable output and browser evidence outside this package.

Read the relevant contract in `references/screen-patterns.md` and preserve shared case state between the views. Use original character names, dialogue, case facts, and evidence. Do not copy Capcom art, portraits, screenshots, logos, or dialogue. This reference package contains no licensed game data or font file.
