# Animal Crossing: New Horizons interface reference

Use this experimental package for original interfaces informed by **2020 Nintendo Switch direction**. It is not a publisher asset pack, exact reconstruction, engine export, or verified gameplay implementation.

Read visual-rules.md, tokens.json, screen-patterns.md, and sources.md in references. Inspect the original style board, reusable vector atlas, and editable component specimens.

The approved screen IDs are pockets, diy-recipes, island-map. Build separate responsive views with clearly labeled synthetic content. Keep runtime files local; no hosted fonts, images, or services are needed. Use cream paper, rounded organic forms, dotted pockets, a handmade recipe card, and an island sketch.

The component page shows editable parts, not completed screens. Reuse only relevant pieces in your own composition.
