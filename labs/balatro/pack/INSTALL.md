# Balatro UI · 使用说明

这是一个给 AI 读取的、非官方 Balatro 风格参考包。版本 1.0.0，实验性本地验证版。

## 使用

1. 解压，保留整个 `balatro-ui` 文件夹及其相对目录结构。
2. 放到你的 AI Agent 支持的 Skills 目录，然后按该工具的方式加载。也可以直接把本地 `SKILL.md` 路径发给能读文件和图片的 AI。
3. 让 AI 先读取规则并查看参考图、组件板和物品图集，再提出界面需求。

示例：

> 使用这个文件夹里的 balatro-ui Skill。先读取 SKILL.md 和关联规则，查看参考图。为我的游戏制作一个背包界面：12 个格子，支持道具分类、选中详情、使用药水。使用 HTML/CSS/JS，本地打开，文字和数值可以改。

也可以要求奖励三选一、商店，或让 AI 适配已有项目。包内只有组件原语，没有预先写好的完整三屏页面。

## 内容

- `SKILL.md`：任务入口与执行流程。
- `references/`：视觉规则、界面模式、资产说明、验收标准、两张已确认方向图及组件板。
- `assets/tokens.json`：统一配色、几何、间距、字号、图集坐标。
- `assets/components/index.html`：可直接查看的 HTML/CSS 组件样品。
- `assets/items-atlas.png`：透明六件物品图集。
- `assets/fonts/`：Pixelify Sans 与原字体许可证。
- `agents/openai.yaml`：兼容工具的展示元数据。
- `manifest.json`：文件列表、版本、SHA256 和生成来源。

## 能力边界

需要能读取文件、查看图片和生成所需格式的 AI 环境。包本身不调用在线模型，不要求自带 API Key；是否产生模型费用取决于你使用的 AI 工具。额外美术生成需要该工具具备相应能力。

参考图和新物品图集由 AI 生成，不是官方游戏截图或拆包素材。当前验证目标是 Web 界面的一致性；没有验证 Unity、Godot、Unreal 或 Figma 输出。中文使用系统字体回退，不包含中文像素字体。
