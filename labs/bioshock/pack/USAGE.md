# Use this reference skill

Give your AI the whole package so it can use the Art Deco geometry rules, original object atlas, screen contracts, and editable component specimens.

Example request:

> Use the BioShock UI reference skill for three linked screens: tonic vending, plasmid upgrades, and a hacking relay. Keep the 2007 first-game direction with stepped brass geometry, enamel plaques, and restrained marine patina. Use synthetic data in screen-patterns.md and implement purchase, upgrade, and puzzle states in an output folder outside the skill package.

Open `assets/components/index.html` to inspect the local primitives. CSS loads the sibling generated atlas. Adapt selected components rather than presenting the specimens as a full app.

The package has no official game screenshot, no game font, no engine export, and no completed application screens. All tonic names, currency, and puzzle values are invented.
