# Visual rules

## Deco silhouette

Use vertical symmetry, centered medallions, fan rays, stepped corners, and thin repeated borders. Deco geometry must be deliberate and measured; do not scatter gears or pipes as generic steampunk decoration. The main panel is a dark marine-black enamel field, framed by two narrow brass lines and a few cream inlay marks. A subdued sea-green patina can appear only in small accents.

Keep panel edges square or stepped; avoid rounded cards, cyan holographic glow, rust grunge, and loose asymmetry. Use sunburst/radial lines behind a single medallion, not as a busy all-over texture. Header plaques are tall and narrow, like an elevator or machine label. The geometry, not a large illustration, carries the family identity.

## Type and palette

Pair a condensed serif or restrained display serif for short machine titles with a clean sans for row labels and numbers. Use 14–16px body copy and aligned numerals. Main type is aged ivory. Gold communicates frame, cost, and selection. Marine teal is only a rare secondary note. Red means unavailable or hazard and includes a textual reason.

Palette: ink #111b1c, dark enamel #192628, brass #b28b4f, pale gold #d2b475, old ivory #e6ddc7, patina #54716d. Never use bright polished yellow as a page-wide surface.

## Machine components

A tonic shelf row uses a small bottle, a machine-cut label, quantity, and brass price. The active row gets a double brass rule and an angled corner bracket; do not flood it with gold. Upgrade cards show current and preview values in separate columns. A security relay uses a rectangular grid with one highlighted active node and a vertical progress meter; no neon puzzle labyrinth.

Use generated original bottle, key, dial, gauge, and plaque assets as small specimens only. Keep any lettering on local plaques editable HTML text; generated plaques are blank.

## States and accessibility

Purchase preview never spends resources. Confirm deducts a cost exactly once. If unaffordable, disable the control and state the shortfall. Hacking cursor and solved path use both shape and text feedback. Keyboard focus uses a visible ivory inset outline. No flicker or continuous scanline animation; respect reduced motion.

On mobile, stack the plaque above the list and let an individual stock shelf scroll. Retain frame edges but simplify repeated brass lines to two levels.
