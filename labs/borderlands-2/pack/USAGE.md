# Use this reference package

Pass the whole `borderlands-2-ui` folder to your AI. The generated weapon atlas is original art. `assets/components/index.html` demonstrates individual item, rarity, comparison, and node primitives; it is not a ready-made inventory or skill tree.

Suggested request:

> Use the `borderlands-2-ui` reference package to create three connected responsive Web screens for an original sci-fi looter: compare weapons, browse a pack, and spend a skill point in a small connected tree. Reuse the included weapon art, invent every manufacturer and stat, and implement equip, sort, and node-purchase behavior with keyboard and pointer support. Put the finished screens and browser evidence in a separate output folder.

Read the exact screen pattern requested before composing. Keep the view distinctive through weapon silhouettes, stat comparison, rarity grammar, and node links rather than just a saturated palette. Do not copy official weapons, text, logos, characters, screenshots, or sound / animation assets.
