# Use chrono-trigger-ui

Give an AI the complete chrono-trigger-ui folder and point it to SKILL.md. Request one of the authored patterns or describe a new player task, then specify viewport, party data, controls, and required states.

The reference board and assets/art/ui-atlas.svg are original local artwork. assets/components/index.html is an editable, responsive parts board; copy and recompose useful pieces for a new screen. Its controls only change local preview state.

The Steam context link in references/sources.md was opened on 2026-10-16 to identify the linked product. It does not verify the 1995 SNES screen designs in this package. Sample names, stats, and timing are fictional. Save generated work outside this package so the reference inputs remain unchanged.
