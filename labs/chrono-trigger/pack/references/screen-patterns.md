# Screen patterns

## party

Show three member rows with original abstract portraits, name, HP, MP, and a short equipment line when needed. Keep the focused member obvious. Do not invent an equipment effect as if it were source-game data.

## techs

List individual, two-person, and three-person Tech options in a compact blue pane. Each row names its required participants. Show cost/readiness only when supplied by the user or clearly mark values as samples. A selection previews the combination; it does not execute it.

## battle-orders

Place a labeled Active Time Battle strip above or beside the party command queue. Use ready and waiting text with distinct meter shapes. Keep one target preview and focused command visible. On a phone, stack the strip first and retain three distinct party orders.
