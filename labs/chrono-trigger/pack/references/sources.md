# Sources and asset boundaries

## Product context

- [Steam: CHRONO TRIGGER](https://store.steampowered.com/app/613830/) is the product context link selected by the approved plan. Opened on 2026-10-16 to confirm the linked product identity.
- Fixed study target: 1995 Super Nintendo interface direction, not the later PC UI. The plan fixes this scope; the Steam listing is not evidence for the SNES interface details or rules in this package.
- All component geometry and visual rules here are original interpretation. No source-game screen was traced.

## Original package files

- references/images/reference-board.svg and assets/art/ui-atlas.svg are original SVG illustrations. They contain no extracted screenshots, logos, sprites, textures, or recognizable source-game character designs.
- assets/components/index.html and assets/components/theme.css are editable local HTML/CSS specimens. Controls change local presentation state only.
- No external image, font, script, or runtime network request is required.

## Limits

This is an original art-direction study, not an official UI specification or engine export. Example names, stats, participant requirements, and timing states are invented. Search volume and ranking are unknown.
