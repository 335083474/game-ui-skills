# Visual rules

## Compact blue windows

Hold the interface to a compact 16-bit RPG grammar: translucent blue panes, thin luminous edges, a small gold or cyan selection cue, short labels, and crisp spacing. Keep the 1995 Super Nintendo direction separate from later PC interface conventions. Avoid large glossy cards, modern tabs, and oversized empty panels.

## Three-person party, Techs, and ATB

Keep exactly three party slots in the authored examples. Give each member readable HP/MP labels. Tech rows state how many participants they require and visibly name or mark those participants. The Active Time Battle strip distinguishes ready and waiting states by shape and text as well as color.

Do not imply that the specimen simulates timing, damage, or a real battle. A selected Tech is a local preview until the user implements and confirms it.

## Type, responsive behavior, and input

Use system sans for labels, a restrained system serif for short headings, and system monospace for numeric values. Do not fetch fonts. Keep corners square or nearly square; do not round panes into modern mobile cards.

Use semantic buttons, visible focus, stable keyboard order, and 44px touch targets. Reflow windows to one column at narrow widths while keeping the ATB label and state visible. Respect reduced motion; any glow remains still.
