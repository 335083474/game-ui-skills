# Use cuphead-ui

Invoke this package for original interfaces drawing on 1930s rubber-hose cartoon game ui.

Read SKILL.md with visual-rules.md and the pattern for the requested surface. Inspect the editable specimen page in assets/components/index.html, then build a separate application composition using real product state. The specimen controls change only local preview selection; they do not save game data.

The pack is self-contained and requires no downloaded fonts or external runtime. Its illustration is original generated art, not an official Cuphead (2017 base game; separate from The Delicious Last Course) asset. Title-specific demand is unknown. Parent browser capture and fresh implementation QA are pending.
