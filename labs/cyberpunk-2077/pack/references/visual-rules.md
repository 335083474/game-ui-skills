# Visual rules

## Art direction

Street-grade diagnostics: precise, compressed, and slightly unstable at the edges.

## Reusable grammar

- Compose hard, clipped plates and a slanted grid; let headings, asset codes, and thin dividers create density. Avoid rounded mobile cards, soft glass blur, and generic neon gradients.
- Use red for urgent or selected states, cyan for scan/data, and yellow sparingly for warnings. Pair each signal with a label, icon, or shape so meaning never depends on color alone.
- Cyberware should read as a body-slot map with a clear installed/available distinction and one selected implant's impact. Avoid presenting invented values as canonical game balance.
- Journal rows need hierarchy among current objective, related job, and archived entry. Keep descriptive copy short and make the active route/action unmistakable.
- A district map uses abstract street traces, nodes, and labels before decorative city lights. At mobile widths, keep route topology continuous and collapse metadata into a slim inspector strip.
