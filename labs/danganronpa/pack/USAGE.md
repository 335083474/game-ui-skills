# Use this reference package

Give the whole `danganronpa-ui` folder to your AI. The generated student portrait, visual rules, and components define a graphic trial direction. `assets/components/index.html` is a set of primitive specimens, not the three requested screens.

Suggested request:

> Use the `danganronpa-ui` reference package to create three connected responsive Web screens for an original school mystery: a digital student handbook, an evidence locker, and a trial debate. Reuse the included fictional portrait, create new testimony and evidence, and implement a roundtable index, evidence selection, claim matching, and clear pass / miss feedback. Support keyboard controls and keep the finished screens and browser evidence outside the skill folder.

Read the pattern for each requested screen. Preserve the distinction between selected evidence and the active statement. Use restrained transitions and readable copy; do not reproduce any official character, mascot, UI screenshot, dialogue, logo, or game asset.
