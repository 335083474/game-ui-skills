# Sources and interpretation

## Official source

- [Official Steam product page for Darkest Dungeon](https://store.steampowered.com/app/262060/)
- [Approved classic UI implementation plan](../../research/classic-ui/gap-implementation-plan.json), row darkest-dungeon.

The official listing identifies the 2016 original as a gothic roguelike, names psychological stress as a core part of adventuring, and describes a hand-drawn gothic crowquill art style. The plan selects the gothic-ink family and marks this direction as experimental art direction.

## Original work in this package

The local [direction artwork](assets/references/direction-board.svg), [component specimens](assets/components/index.html), [token CSS](assets/tokens.css), and [visual rules](references/visual-rules.md) were authored for this reference package. They do not reuse or trace store screenshots, game UI captures, character art, official logos, or bundled game files. Typography uses local system-font stacks; no font files are bundled.

The screen anatomy and material rules are editorial interpretations. The official source does not validate these specimens as canonical game UI. This package makes no measured search-demand claim and does not provide an engine-ready implementation.
