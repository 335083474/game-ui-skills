# Dead Space visual reference

Use this experimental package within the approved 2023 remake scope. It is a diegetic interface study, not an EA asset pack or a screen reconstruction.

Read visual-rules.md, tokens.json, screen-patterns.md, and demo-state.json. Inspect style-board.png for generated industrial context and assets/components/index.html for inventory, kiosk, and locator primitives. The generated plate is separate from EA’s product reference.

Keep each projection attached to a suit, terminal, or route context. Equipment compares modules, the store confirms one transaction, and the locator communicates bearing and distance. Use thin cyan lines over dark engineered backing; avoid generic dashboards and bright cyan-filled panels.

All equipment names, prices, credits, ranges, status, and outcomes are synthetic. The Web specimens imitate projected UI with HTML/CSS; they are not a 3D engine implementation.
