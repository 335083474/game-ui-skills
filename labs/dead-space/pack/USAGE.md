# Usage

Use this package for original survival-sci-fi interfaces that feel projected into the environment and remain readable.

1. Read visual-rules.md and tokens.json, then choose a pattern in screen-patterns.md.
2. Treat style-board.png as generated context art, not official artwork.
3. Keep inventory comparison, purchase confirmation, and route tracking as separate information jobs.
4. Label equipment, prices, balances, ranges, and behavior as synthetic. Show preview before commit; reload resets the local specimen.
5. Use system fonts and local CSS. Do not claim camera-space, 3D depth, engine integration, or exported runtime UI.

Open assets/components/index.html locally. Its interactions change only temporary page state.
