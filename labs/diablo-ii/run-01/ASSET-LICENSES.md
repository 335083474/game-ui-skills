# Asset provenance

This is an original Diablo II classic inspired study. It contains no Blizzard logos, extracted game sprites, proprietary game fonts or official screenshots.

- `assets/items-atlas.png`: original generated transparent art supplied by the frozen `diablo-ii-ui` experimental reference Skill. The six cells are sword, helmet, potion, shield, amulet and flame. Reused unchanged. This provenance statement is not a blanket third-party licensing or production-use clearance.
- `assets/components/theme.css`: the frozen Skill's editable specimen theme, reused as the base for fonts, CSS stone, bevels, item atlas and resource globes.
- `assets/fonts/alegreya-sc/`: Alegreya SC Regular and Bold; the packaged SIL Open Font License is retained at `assets/fonts/alegreya-sc/OFL.txt`.
- `assets/fonts/crimson-text/`: Crimson Text Regular and Bold; the packaged SIL Open Font License is retained at `assets/fonts/crimson-text/OFL.txt`.
- New layouts, original names, demo data, state logic, simple inline engraved skill symbols and empty-well silhouettes were authored for this prototype. The flame emblem is a reused specimen, not distinct official skill artwork.

The generated direction image and board capture were inspected as reference only and are not shipped or embedded as finished screens.
