# Screen patterns

Use one fictional detective, one invented district case, and one small set of skills / thoughts across all views. These patterns guide composition and state; they are not finished screen layouts.

## Dialogue and check

Make the dialogue feed the main reading surface. Each paragraph has an optional speaker marker; internal voice lines use a distinct skill label and small tonal shift. Place choices directly after the relevant text as short lines, not as a stack of equal rounded buttons. A check interruption shows the skill, target, base chance, modifiers, and resolution. Keep the player's previous reading position when opening a detail. Selecting a choice previews its consequence; only confirm advances the case state. A failed check should change the story state without hiding the failure behind color.

Synthetic example: “The dock ledger is damp at the corners.” The Archivist voice notices a missing day. A Logic check starts at 42%, receives +10% for a clue and −8% for fatigue, then resolves to a labeled pass/fail state. These values and dialogue are invented.

## Skills

Show skills in a compact grouped index with a readable current value. Selecting one reveals its voice description, relevant modifiers, and current case tie-in. Keep the explanation distinct from the scrolling dialogue transcript. Use values, tags, and words such as “low / steady / strong” together where needed; never communicate a statistic with color alone. Changes from equipment or temporary conditions appear as a signed modifier line, not as a silently changing bar. The back action returns to the same selected skill and scroll position.

Synthetic example: Logic 4, Empathy 3, Composure 2. A clue adds +1 to Logic for one named check only. The example does not assert the game's actual skill formulas.

## Thought cabinet

Use an asymmetrical pinboard of a few idea slips. Each thought has a source phrase, a state (“considering,” “internalizing,” or “formed”), progress, and a plain-language effect. Choosing to internalize should make the time / progress cost explicit; cancel leaves it unchanged. Completion applies its synthetic effect once. A thought can be forgotten only through a separate confirm step, with its effect removal stated. Keep long idea text in a detail panel instead of spreading tiny copy across all slips.

Synthetic example: “The Missing Shift” has 2 of 3 steps complete and grants a temporary +1 interview detail after completion. This effect is invented, reversible in the demo, and not a game mechanic claim.
