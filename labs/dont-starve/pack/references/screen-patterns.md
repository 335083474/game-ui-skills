# Screen patterns

These are composition contracts for new work, not finished game screenshots. The component specimen uses synthetic content and original vector art.

## `crafting` — Workbench

Recipe rows emphasize object, material requirement, and a clear craft or missing-material action.

**Sample state:** A recipe is an object, a cost, and a small decision about what the dark will take.

## `inventory` — Field Pack

Compact object slots keep silhouette and stack count adjacent, with breathing room between items.

**Sample state:** Rough slots keep the quantity close to its object. Empty space is still useful.

## `survival-hud` — Nightfall HUD

A sparse edge HUD labels each survival need and leaves the world view open. Keep longer inventory details behind a menu.

**Sample state:** Three labeled needs, one next action, and a mostly clear patch of forest.

## Shared interaction

Use semantic controls, visible keyboard focus, labeled selected and unavailable states, and a responsive layout. Keep motion restrained and respect reduced-motion preferences.
