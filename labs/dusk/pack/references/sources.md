# Sources and boundaries

## Product reference

- [DUSK — supplied reference page](https://store.steampowered.com/app/519860/) is the product/source link recorded in `research/classic-ui/gap-implementation-plan.json`. It was not opened or re-verified during this package-authoring pass. Treat it as an identification and context link, not as evidence for exact interface details.
- Fixed target: 2018 original / low-resolution 3D direction; not HD remaster.
- The interface grammar in this package is an original design interpretation. It is not a screenshot analysis or official UI specification.

## Original package art

- `assets/art/scene.svg`, `assets/art/icons.svg`, and `references/images/style-reference.svg` are original local vector files made for this package. They contain no source-game screenshots, extracted textures, official logos, or character art.
- `assets/components/index.html` and `assets/components/theme.css` are editable local HTML/CSS component specimens. The controls only update local presentation state.
- No external fonts, images, scripts, or runtime network requests are used.

## Limits

- The corridor, weapon silhouettes, controls, and numbers are original vector artwork and synthetic examples; no DUSK game assets or font are included.
- The art target is the original 2018 low-resolution 3D direction, not DUSK HD or a captured game screen.
- No engine integration, gameplay logic, or measured search-demand evidence is included.
- Search volume, ranking, and product demand are unknown; this package makes no demand claim.
- No game engine export or full-screen usage test is included.
