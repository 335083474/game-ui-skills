# Use earthbound-ui

Give an AI the complete earthbound-ui folder and point it to SKILL.md. Request one of the authored patterns or describe a new player task, then specify viewport, controls, content, and required states.

The reference board and assets/art/ui-atlas.svg are original local artwork. assets/components/index.html is an editable, responsive parts board; copy and recompose useful pieces for a new screen. Its controls only change local preview state.

The official Nintendo context page in references/sources.md was opened on 2026-10-16 to confirm product identity and platform context. It does not verify the screen designs in this package. Sample names, counts, and statuses are fictional. Save generated work outside this package so the reference inputs remain unchanged.
