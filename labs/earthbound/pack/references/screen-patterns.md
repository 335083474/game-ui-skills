# Screen patterns

## goods

Use one rounded inventory window with ordinary object names, quantities, and one selected row. Keep one short preview line for the selection. Do not use rarity color as the only distinction; use text and quantity. Separate inspect from use.

## party-status

Give each of four party members a readable row with name, HP, PP, and a short condition when needed. Label any rolling-HP trail and clearly mark its numbers as demo data. Do not hide low values behind animation.

## battle-commands

Keep the battle field vivid and the command window stable. Show action, target, and preview separately. Make the selected command and keyboard focus visible. A psychedelic scene must not obscure the controls or imply that the specimen ran combat.
