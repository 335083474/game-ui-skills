# Visual rules

## Art direction

A battered desktop field terminal assembled from serviceable panels and readable numbers.

## Reusable grammar

- Use the language of a late-1990s PC interface: compact windows, square buttons, bitmap-like separators, dense labels, and small original pictograms. Avoid current mobile-card spacing and giant touch controls.
- Treat metal as a frame, not a full-screen texture. Muted steel, dusty cream, rust, rivet points, and small green monochrome readouts create hierarchy; preserve high contrast for numbers and labels.
- Keep character attributes, carried inventory, and barter as separate task surfaces with the same engraved labels and hardware seams. Use persistent left/right alignment for comparisons.
- This package explicitly excludes the modern wrist-mounted Pip-Boy visual direction. Do not use a wrist screen, radial wrist menu, Fallout 4 styling, copied Vault-Tec marks, or canonical character art.
- For narrow layouts, preserve dense data through a one-column inspector and horizontal tab strip. Provide a text description for every icon and a visible keyboard focus state.

The product page and original-art boundary are recorded in [sources.md](sources.md). Treat every supplied number, item, route, and status as a synthetic specimen unless a future output has its own authoritative data source.
