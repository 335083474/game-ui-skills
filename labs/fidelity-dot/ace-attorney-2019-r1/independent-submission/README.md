## 操作

选择态：
- 鼠标选择实际存在的1–6个槽位。
- 槽位有焦点时，左右键、Home、End选择；Enter/Space打开完整文字。
- 槽位或说明区域有焦点时，S打开确认；也可点击提交证物。
- 编辑器、导入、导出按钮的按键不会被舞台全局提交快捷键抢占。

确认态：
- 初始焦点为取消按钮，降低误提交风险。
- 焦点在取消：Enter/Space或鼠标点击取消，返回选择。
- 焦点在确认提交：Enter/Space或鼠标点击才提交。
- Esc取消。按Tab/Shift+Tab在当前确认区域的可操作控件及可滚动说明中循环。
- 底层选择区域隐藏并inert；舞台外编辑器和顶栏也inert。
- 没有“任何地方按Enter都提交”的document映射。

结果态：
- 显示提交时所选证物的独立数据副本；不提交网络、不改变案件或真实游戏进度。
- 返回重新选择按钮由正常Enter/Space/鼠标激活；Esc也返回选择。
- 焦点返回原提交按钮，或仍存在的原选中槽位；不存在时降级至当前选中槽位。

完整文字：
- 选择态有舞台外完整文字按钮；确认/结果内部均有完整文字按钮。
- 名称固定高度省略，说明在有界区域滚动。全文弹窗包含完整名称和说明，不截断源字符串。
- 全文弹窗为原生模态dialog；关闭按钮或Esc关闭后恢复触发控件焦点。确认/结果仍保持隔离，不暴露底层。
- 完整文字内容区可Tab聚焦和滚动。

## 数据输入输出

编辑submission-data.js并刷新，或在下方JSON编辑器中粘贴后校验导入。刷新恢复启动文件；没有隐式保存。导出触发本地submission-candidates.json下载，不代表浏览器一定已保存文件，须由接收方实际检查。

合法最小输入：

    {
      "schemaVersion": 1,
      "version": "AA2019-submission-v0.1",
      "selectedId": "note",
      "items": [{
        "id": "note",
        "name": "Witness Note",
        "icon": "note",
        "description": "Editable full text."
      }]
    }

契约保持：
- items必须1–6项；0项和7项拒绝。
- ID唯一，1–40位ASCII字母、数字、下划线或连字符，首位字母/数字。
- selectedId为现有ID或null；null规范为首项ID。不存在的非空ID拒绝。
- name最多300、description最多20000个UTF-16 code units，允许空字符串。
- icon仅允许badge/statue/shards/note/phone/envelope。键映射到固定本地文件，不能传URL、相对穿越路径或任意图片。
- 字段必须完整且不得有额外字段；类型、重复ID、超长字符串、非法图标、JSON语法及超过1000000字符的输入均拒绝。
- 导入先完成全部校验，再替换数据。失败保留原数据、选择及编辑器待修JSON。
- 合法导入替换候选后聚焦选中槽位。导出保存完整文字、图标键和当前selectedId。

## 必须实际回归的成功/失败用例

1. 取消聚焦后Enter、Space、鼠标：都回到选择，无提交结果。
2. 确认按钮Enter、Space、鼠标：仅在确认态生成结果；长按Enter不得连续跨状态执行。
3. Esc取消；确认/结果Tab和Shift+Tab不进入底层submitBtn、槽位或编辑器。
4. 当前模态的全文按钮可达；弹窗关闭后回到该按钮，之后仍可取消/确认。
5. 1和6候选、普通文字和300名/20000正文，确认/结果图标、名称与实际所选项一致，全文和真实导出保持完整。
6. 返回重新选择后能选另一项并提交；鼠标、键盘焦点都有可见反馈。
7. 0/7项、重复ID、../private.svg、超长字段及坏JSON拒绝；旧数据可继续导出。
8. 960×540实际舞台及常见宽屏：白纸文字无底层重影，操作区、滚动区和焦点边线不相交；竖屏限制明确。
9. 确认中缩小窗口再恢复，状态和焦点隔离不丢失。
