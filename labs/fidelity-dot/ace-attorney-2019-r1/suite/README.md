## Editing
Click slots, use Left/Right/Home/End, Enter/Space for full text, Escape to return.
Outside-stage Review/edit supports selected-item changes and whole JSON.
Load current JSON fills the text editor; Import validates atomically.
Invalid data leaves current collection/selection intact.
Add/Remove support0–10 entries;11 is rejected.
Empty collection has no selected image, no modulo and an editor fallback.

Export before reloading or navigating. Reload restores startup data.
There is no automatic storage or cross-page persistence.
Use Evidence's DATA-CONTRACT.md and Profiles' PROFILES-README.md for exact schemas.
Evidence JSON cannot be imported as Profiles JSON.
