## 12项候选的可达性
候选上限仍是12，不降为6。
每页最多6项，固定三列两行；第7..12项在第2页。
面板内的上一页/下一页和页码始终保留自己的布局空间。
没有把第三、四行渲染到岛民留言上，也不靠裁掉超出部分作为分页。
Tab可进入页内有效候选及分页按钮。
候选内方向键按数据顺序移动到上一/下一件可添加物品，跨页自动切换。
Home/End到全部候选中的首/末有效项。不是只在当前页循环。
鼠标可用分页按钮；库存0、已达到库存或已交付的候选不可添加。
一页无可添加物品时仍可翻页查看；焦点回有效分页按钮或全文入口。

点击/Enter/Space添加一件。每个候选仍使用独立同源图标。
物品名一行省略，需/有分别占独立16px行；每个四位数不挤占名称。

## 清单与焦点
清单内部独立纵向滚动，不扩大外面板或压住留言。
每行上部显示名称和两行需/有，下面独立一行显示减/数量/加/移除。
数量最大9999，输出框独占66px，数字与操作按钮间保留8px间距。
长名称在独立24px行省略，不压库存或数量控件。

重绘前后使用逻辑焦点：
1. 普通候选添加：仍回到同物品候选，连续Enter/Space可继续添加。
2. 候选达到库存上限变禁用：转到同物品清单的“减少”。
3. 普通清单增减：仍回同物品同操作。
4. “增加”达到上限：同物品“减少”优先，不能落到BODY。
5. 数量1再减少或移除整行：优先原索引处的下一行同操作，之后前一行；
   若清单已空则回该物品可添加候选，再降级其他可添加项、提交或全文。
6. 清单焦点恢复时，只滚动清单内部使该行可见，不把整个页面跳到别处。
7. 编辑/导入/空清单等工具操作保留对应工具焦点；不会强行跳回舞台。
8. 确认取消回提交；确认成功进入结果弹窗；结果关闭回全文入口。
   确认弹窗的close事件不会抢走已打开结果弹窗的焦点。

以上是实现规则，不是宣称浏览器实际复验已通过。
