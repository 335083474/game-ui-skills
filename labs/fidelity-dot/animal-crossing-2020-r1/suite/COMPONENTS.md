# ACNH-pockets-v0.3 component framing

## 蝎子专用取景

原资产不变：assets/scorpion.png，接收方测量1150×1367 RGBA，734454字节。
主体alpha≥128范围：x221..925，y286..1162；704×876。
取景框：x185、y245、w780、h960。

容器必须保持780:960比例。图像定位共用：
- left = -185/780 × 100% = -23.7179487179%
- top = -245/960 × 100% = -25.5208333333%
- width = 1150/780 × 100% = 147.4358974359%
- height = 1367/960 × 100% = 142.3958333333%

CSS规则.iconViewport[data-icon="scorpion"]>img同时应用槽位和详情。
因容器与取景框比例相同，图像width/height是等比映射，不是扭曲形体。

槽位容器55.25×68，left4.375/top0，置于原64×68按钮中；主体理论704×68/960=49.8667，876×68/960=62.05。
详情容器91×112，同样的原图取景；主体理论82.1333×102.2。

容器矩形overflow:hidden仅对新生成资产留白取景。详情黄底用径向渐变，不用圆形border-radius额外切掉钳/尾。
工具默认64×68或详情112×112，object-fit:contain，不应用蝎子裁框。

## 保留的viewport规则

实际可用空间来自documentElement.clientWidth/clientHeight及visualViewport存在时的较小值。
scale=floor(min(1,width/1280,height/720)*1000000)/1000000。
实际舞台至少960×540且横屏才启用。常驻可见纵向滚动槽、编辑器宽度约束和resize监听继承v0.2；没有隐藏横向滚动来掩盖裁切。
