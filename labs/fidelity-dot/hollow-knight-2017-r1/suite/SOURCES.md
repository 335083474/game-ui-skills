## Text and demonstration accuracy

Old Nail and its default description are visible in the supplied Inventory
reference. Initial Geo 540 and the representative layout follow that image.
Other labels/descriptions are editable demonstration content. Tied Scroll and
Pink Crest are descriptive placeholders, not verified game terminology.

The Inventory Press X prototype action opens information, not combat. Save slot
contents and Pause labels/help/modes are demonstration state. Completion limit
112, volume values and data limits describe this prototype; they are not an
assertion of official game mechanics. No genuine game-save compatibility, audio
engine integration or persistent cloud storage is established.

## Fonts and local dependencies

Times New Roman / Georgia / serif refer to installed system fonts. No font
binaries or new font license are supplied. They are substitutes, not confirmed
official game fonts. Metrics and rendering can vary with browser and platform.

The pages use local relative HTML/CSS/JS/SVG/PNG dependencies. No npm library,
hosted API, secret or network font is required for ordinary UI rendering.
shared-style.css is retained for the Pause page as the exact base style.css
copy used by its independent maker. It is a dependency copy, not an additional
font or artwork source.
