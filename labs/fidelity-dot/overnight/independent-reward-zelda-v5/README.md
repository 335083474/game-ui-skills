# Independent reward-screen example

Open [the reward screen](index.html) from this published folder. It uses the adjacent local components, pixel fonts and data files. It is a separate example made using the frozen Zelda v5 reference package.

The original game reference is The Legend of Zelda: A Link to the Past (1991 SNES/SFC). This is an authored approximation. It is not an official asset pack and no commercial game-IP clearance is asserted.

The linked ZIP and producer erratum are on the [latest sample page](../index.html). Internal receiver paths and test logs are not included in this public preview.
