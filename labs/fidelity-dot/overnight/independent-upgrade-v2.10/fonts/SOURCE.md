# Active local fonts

Actual font binaries are in the separate v2.10 font ZIP, not the code ZIP. Copy its fonts/ folder into this code root. Exact paths and hashes are in ../font-manifest.json.

Official sources: https://github.com/google/fonts/tree/main/ofl/alegreyasans ; https://github.com/google/fonts/tree/main/ofl/alegreyasanssc ; https://github.com/google/fonts/tree/main/ofl/spectralsc . Designers: https://github.com/huertatipografica/Alegreya-Sans and https://github.com/productiontype/Spectral .

Unmodified OFL 1.1 fonts; family-specific license notices included. They are source-backed candidates, not an assertion of exact original Hades font file/version. Header uses Spectral SC Regular, names/rarity Alegreya Sans SC Regular, body Alegreya Sans Regular and bold stats.
