# Screen patterns

These are composition contracts for new work, not finished game screenshots. The component specimen uses synthetic content and original vector art.

## `character` — Traveler Profile

A character profile pairs an original figure with a name, role, and a small number of labeled attributes.

**Sample state:** An original traveler profile keeps the name, role, and essential attributes beside the figure.

## `equipment` — Equipment

Equipment highlights the named slot and one comparison value while secondary set context stays quiet.

**Sample state:** Each gear slot gets a clear icon, a short name, and the one stat worth comparing.

## `quest-journal` — Travel Journal

One tracked objective leads; optional and discovered notes remain visibly secondary.

**Sample state:** Keep one current objective distinct from optional discoveries and completed notes.

## Shared interaction

Use semantic controls, visible keyboard focus, labeled selected and unavailable states, and a responsive layout. Keep motion restrained and respect reduced-motion preferences.
