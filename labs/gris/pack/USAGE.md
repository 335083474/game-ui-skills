# Package use

Read SKILL.md and the pattern for the requested surface. The package is local and self-contained: open assets/components/index.html in a browser to inspect its chapter, memory, and pause specimens.

The generated watercolor architecture plate is an original mood reference. The example chapter names and memory record are synthetic. Replace them with the user's actual game state. A chapter is not entered until a separate confirmation action is chosen; reading or closing a memory does not alter collection state.

This package provides editable Web specimens and a visual reference Skill. It does not include GRIS artwork, a game engine scene, or a tested engine export.
