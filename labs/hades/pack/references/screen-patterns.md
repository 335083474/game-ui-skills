# Screen patterns

These are composition contracts for new work, not finished game screenshots. The component specimen uses synthetic content and original vector art.

## `boon-choice` — Boon Choice

Three offerings share one visual weight until a single choice is selected. Keep category, effect, and confirm action distinct.

**Sample state:** Three powers answer the same descent. Choose the one that changes your next move.

## `weapon-aspects` — Weapon Aspects

Each weapon aspect combines a recognizable armament emblem, a concise handling note, and an explicit weapon label.

**Sample state:** Each aspect changes the rhythm of a familiar weapon. The labels below are original study content.

## `keepsakes` — Keepsakes

Keepsakes read as small personal objects with a visible worn, available, or found state.

**Sample state:** Small tokens carry a personal story into a dangerous room. Select one to prepare the next passage.

## Shared interaction

Use semantic controls, visible keyboard focus, labeled selected and unavailable states, and a responsive layout. Keep motion restrained and respect reduced-motion preferences.
