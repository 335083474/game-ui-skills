# Her Story interface reference

Use this experimental reference to create original interfaces informed by the searchable interview-database premise of *Her Story* (2015). It is not an official asset pack or a reconstruction of the original application.

Read [visual rules](references/visual-rules.md), [screen patterns](references/screen-patterns.md), and [sources and limits](references/sources.md). Reuse the original local marks and the editable specimens in [assets/components/index.html](assets/components/index.html). The specimen page is a component plate, not a finished game screen.

Treat the database as the primary interaction: make query, match count, clip identifier, and transcript snippet easy to scan. Keep the archival surface warm, slightly worn, and mechanically precise. Use small text labels, restrained scanlines, and compact transport controls. Let the user search the supplied sample content and inspect metadata.

The package contains no game footage, audio, actor likeness, or official screenshots. All sample clips and transcript fragments are invented. If the user supplies no licensed video, use an empty or illustrated placeholder with an unmistakable `SIMULATED / NO FOOTAGE` label. A play-shaped control may change selected-clip metadata only; do not imply that video or audio is playing.

All interface art is original vector work. Preserve the boundary between the source game's confirmed search-and-video premise and this package's editorial colors, typography, and layout. See [USAGE.md](USAGE.md) for a ready-to-use prompt.
