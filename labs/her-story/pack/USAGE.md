# Use the Her Story UI reference

Give your AI the complete package so it can read the visual rules, local art, tokens, and interaction contract together.

Example request:

> Use the Her Story interface reference to build three connected Web interfaces: keyword search, clip library, and case notes. Use the invented data in `references/screen-patterns.md`, keep every clip visibly marked as simulated because no footage is supplied, and make search, selection, and note linking work. Save implementation and screenshots outside this package.

Open `assets/components/index.html` for editable HTML/CSS specimens. Reuse its archive frame, search results, clip metadata, and note-card primitives, then compose each requested screen independently. Read `references/sources.md` before making claims about the original game.

The sample query and results are real, searchable demo content created for this package. The clip state is metadata-only: no video, audio, codec, or playback behavior is included. All screen content and vector art are original studies; there are no official game assets or actor likenesses in this package.
