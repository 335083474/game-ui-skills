# Heroes of Might and Magic III interface reference

Use this experimental package for original interfaces informed by **1999 Complete original direction; not HD**. It is not a publisher asset pack, exact reconstruction, engine export, or verified gameplay implementation.

Read visual-rules.md, tokens.json, screen-patterns.md, and sources.md in references. Inspect the original style board, reusable vector atlas, and editable component specimens.

The approved screen IDs are hero-sheet, town-recruitment, spellbook. Build separate responsive views with clearly labeled synthetic content. Keep runtime files local; no hosted fonts, images, or services are needed. Separate a dense hero ledger, town recruitment roster, and open spellbook; frame values with parchment, dark wood, and restrained gold.

The component page shows editable parts, not completed screens. Reuse only relevant pieces in your own composition.
