# Use hollow-knight-ui

Give the complete `hollow-knight-ui` folder to an AI that can read local files and SVG. Point it to [SKILL.md](SKILL.md), name the player task and desired screen pattern, and specify platform, viewport, actions, required states, and content. Save new work outside this package so the reference inputs remain reusable.

The editable [component specimen](assets/components/index.html) is a local parts board with three selectable sample patterns. It is not an output screen to return unchanged. The local [tokens](assets/tokens.css), [original art](assets/art/hero-illustration.svg), and [icon atlas](assets/art/icons.svg) may be adapted with attribution to this experimental package.

Use [visual rules](references/visual-rules.md) and [screen patterns](references/screen-patterns.md) for reusable composition decisions. Product facts and art boundaries are in [sources](references/sources.md). No official game artwork or font is included.
