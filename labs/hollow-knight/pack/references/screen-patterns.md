# Screen patterns

These are composition contracts for new work, not finished game screenshots. The component specimen uses synthetic content and original vector art.

## `charms` — Charm Rack

Circular charm sockets expose notch cost, worn state, and a single effect; avoid hiding capacity in color.

**Sample state:** Set a small collection of found charms into the worn ring before entering the next room.

## `inventory` — Satchel

Compact object slots keep silhouette and stack count adjacent, with breathing room between items.

**Sample state:** A handful of found objects, counted plainly and spaced for quick recognition.

## `kingdom-map` — Kingdom Map

Connected room nodes communicate entry, current position, and an unseen path; do not let the map read like a shop shelf.

**Sample state:** Follow the linked rooms; the pale node marks the current crossing.

## Shared interaction

Use semantic controls, visible keyboard focus, labeled selected and unavailable states, and a responsive layout. Keep motion restrained and respect reduced-motion preferences.
