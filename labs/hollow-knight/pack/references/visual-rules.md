# Visual rules

## Shape and material

Use a deep ink-blue cave with soft fog at the edges. Frame information with delicate, pale curves, pearl lines, and small notches; let open darkness carry as much weight as the frame. Keep ornament slim and organic rather than metallic or mechanical.

## Type and emphasis

Use a restrained book serif for place names and a clean small sans for inventory labels. Keep the brightest white for the current selection, a map beacon, or a focal charm. Use shape and text along with color to identify active and empty slots.

## Charm and map grammar

Charms sit in circular sockets with visible notch marks. Inventory uses a quiet grid of object silhouettes and counts. A kingdom map is a connected path of labeled rooms with one current node; it should read as geography, not a row of product cards.

## Adaptation

Use [screen-patterns.md](screen-patterns.md) for the approved charm, inventory, and map variations. Preserve a mostly open cave or playfield when the UI overlays movement. This package is an original interpretation of the 2017 first game direction, not Silksong.
