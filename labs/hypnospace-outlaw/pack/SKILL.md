# Hypnospace Outlaw desktop interface reference

Use this experimental package to create original interfaces informed by the customizable 1990s-internet and desktop premise of *Hypnospace Outlaw* (2019). It is not an official asset pack, a browser implementation, or an exact reconstruction of the game.

Read [visual rules](references/visual-rules.md), [screen patterns](references/screen-patterns.md), and [sources and limits](references/sources.md). The local wallpaper illustration and editable window specimens are in [assets/components/index.html](assets/components/index.html). That file is a component plate, not a complete desktop screen.

Use a bright wallpaper field and chunky square window chrome with simple title bars, bevels, and clear minimize/restore/close controls. Early-web pages may use bold color, tiled patterns, centered novelty headings, and dense but legible link lists. Keep browser windows, mail, and file collections visually distinct while sharing the same desktop materials.

All websites, names, messages, downloads, profile art, and actions in this package are invented. The wallpaper and pixel-style icons are original local SVG/CSS work. No official screenshots, logos, game files, fonts, or copied web pages are included. A local “download” or window control must update only the visible demo state and must not imply that a real file was fetched or installed.

See [USAGE.md](USAGE.md) for a prompt covering the three approved screen types.
