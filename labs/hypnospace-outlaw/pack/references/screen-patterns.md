# Screen and state patterns

All pages, mail, filenames, senders, dates, and messages below are original fictional samples. They are not copied from the game.

## Desktop — `desktop`

Use a vivid wallpaper titled `Pond Party` with a small desktop icon cluster. Show original windows such as `Mara's Reef Page`, `HypnOS Notes`, and `Downloads`. Start with the browser specimen open. Window controls minimize, restore, or close only the local demo window; reopening restores its component state. Keep desktop shortcuts keyboard reachable and label the page as a fictional workspace.

## Mail — `mail`

Use a dense inbox with three messages: `Auntie Lune / New fish on my page! / 09:14`, `HypnoMail / Your weekly notice / 08:02`, and `Tadpole77 / Check this link / Yesterday`. The detail panel for the first message reads: `I added a new little fish counter to the reef page. Tell me if the colors look okay!` All copy is invented. Selecting rows changes the visible detail; suspicious links should remain inert and get a clear warning label.

## File Library — `file-library`

Show three fictional items: `PondParty.wll / wallpaper / 420 KB`, `BubbleCount.hpx / helper app / 86 KB`, and `MoonDial.scr / screensaver / 1.2 MB`. Each file shows a local-only state. “Mark for demo” toggles `MARKED IN THIS PAGE`; it does not download, install, or create a file.

## Shared interaction contract

Keep the wallpaper, browser page name, sender, and file labels consistent across all three screens. Closing and reopening a window changes only visibility. Mail selection changes only the detail panel. File selection changes only its local demo state. No external URL, download, or installation is required.
