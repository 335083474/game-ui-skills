# Visual rules

## Desktop color and material

Build the desktop around a playful original wallpaper with saturated teal, violet, pink, aqua, lime, or sky-blue shapes. Keep the surface bright and lively. Do not use the tobacco-paper archive tone, interview-window scanlines, or the cream/cyan scientific map language from other references.

Windows use square corners, thin dark outlines, raised title bars, and simple bevel highlights. Give window controls clear glyphs and visible button edges. Use small pixel-like illustrations and repeated wallpaper motifs as local SVG art; rely on system fonts rather than a bundled or copied game font. Avoid modern floating cards, rounded SaaS panels, glass blur, and large soft shadows.

## Early-web page language

Make a browser page feel handmade: a bold novelty headline, visible URL/address strip, chunky link colors, tiny original decorative badges, and asymmetrical content columns when appropriate. Keep page content readable and preserve a plain link-list rhythm. Decorative motifs should frame the text, not obscure it.

## Mail and files

Inbox rows should show sender, subject, and a small date or status with familiar list density. Mail detail is its own window, not a full-width notification. File libraries use original pixel-style icons, filenames, short descriptions, and explicit state such as `SAVED LOCALLY IN DEMO` or `NOT DOWNLOADED`.

Use local data only. A mark-download action may toggle an in-page label, but must not fetch, install, or claim to save an actual file. Any fictional warning, adware, or suspicious item needs a text label and an obvious action boundary.

## Window interaction and responsive behavior

Use semantic buttons for minimize, restore, close, mail selection, and file-state changes. Keep keyboard focus visible and expose state through text and ARIA where useful. In a narrow viewport, preserve the playful desktop color but stack windows in reading order, reduce wallpaper prominence behind text, and keep controls easy to reach. Do not force a miniature 1990s monitor viewport that makes copy unreadable.
