# Use this reference package

Give your AI the complete `inscryption-ui` folder. Ask it to compose new screens from the guidance and primitives; `assets/components/index.html` is only an isolated specimen board, not one of the target screens.

Suggested request:

> Use the `inscryption-ui` reference package to build three connected, responsive Web screens for a fictional forest-card roguelike: a card reward, a deck binder, and a trade table. Reuse the local woodcut atlas, keep Act 1 tabletop grammar, invent all names and values, and implement selection, affordability, add/remove, and exchange state. Save the runnable app and browser evidence outside the skill folder.

Read the matching screen contract in `references/screen-patterns.md` before composing each view. Keep generated screen layouts and validation evidence outside the frozen package. The sample creature atlas is the only included raster art; fonts, game code, official game screenshots, and extracted game assets are not included.
