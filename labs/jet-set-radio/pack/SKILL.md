# Jet Set Radio visual reference

Use this experimental reference package for original interfaces informed by the 2012 PC HD release’s approved street-graffiti and cel-shaded direction. It is a design study, not a SEGA asset pack or a reconstruction.

Read [visual-rules.md](references/visual-rules.md), [tokens.json](references/tokens.json), [screen-patterns.md](references/screen-patterns.md), and [demo-state.json](references/demo-state.json). Inspect [style-board.png](references/images/style-board.png) for generated context art and [the component specimens](assets/components/index.html) for reusable pieces. The generated art is separate from primary game references and contains no copied character or logo.

Treat crew identity, city route planning, and graffiti results as three different information jobs. Use sharp ink boundaries, paint swipes, sticker layers, rhythmic labels, and visible route motion. Do not reuse Splatoon’s ink-and-sticker grammar, existing Jet Set Radio characters, official logos, or game graffiti. Keep long information on a clean backing surface so the energetic marks never reduce reading contrast.

All names, streets, routes, scores, and interaction outcomes in this package are synthetic. The HTML specimen uses local CSS and browser controls only. It does not implement skating gameplay or an engine export.
