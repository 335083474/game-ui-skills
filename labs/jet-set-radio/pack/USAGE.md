# Usage

Use this package when an original arcade street-skating interface should feel quick, loud, and hand-marked while staying readable.

1. Read visual-rules.md and tokens.json, then choose the relevant screen pattern in screen-patterns.md.
2. Use the original style-board.png only as mood context. It is generated art, not a screenshot or primary reference.
3. Build with the components in assets/components/theme.css. Keep the three information jobs distinct: crew identity, a route decision, and a performance result.
4. Label invented names, values, and local demo controls as synthetic. Keep the interface offline, keyboard-operable, and responsive.
5. Preserve the source boundary: do not copy official characters, logos, graffiti, art, exact screen layouts, or claim an engine-ready export.

The component entry is a standalone local HTML file. Its buttons only change temporary page state.
