# Source and asset provenance

## Primary reference

- SEGA-published Steam listing for Jet Set Radio: https://store.steampowered.com/app/205950/
- The listing identifies SEGA as publisher and gives the PC listing date as 19 Sep 2012. It also describes the HD Heritage Collection treatment. The store page currently says the product is no longer available. This supports the package’s 2012 PC HD scope; it does not validate every proposed visual rule or any exact screen layout.
- Version scope was fixed in the approved local implementation plan as “2012 PC HD”; the interface grammar here is an experimental interpretation of that approved art direction.

## Generated context artwork

- references/images/style-board.png is original generated context art produced for this package on 2026-10-16. It depicts an invented skater and street. It is not primary game reference material or a game screenshot.
- The original was generated with constraints against known characters, existing logos, copied graffiti, and readable text.
- No official game art, font, logo, character face, graffiti design, or code is included.

## Scope limits

The evidence supports the release listing and its broad public description. It does not verify original UI assets, exact control mappings, score math, ranking rules, street layouts, or licensed reuse. Demo data and component behavior are synthetic. The package is a browser DOM/CSS reference, not an engine export.
