# Package use

Read SKILL.md and the screen pattern you need. Open assets/components/index.html to inspect the local gate, progress, and companion-signal specimens. The example uses bundled generated art, local CSS and JavaScript, and installed system fonts; it requires no build step or network access.

Treat the sample waypoints and fellow-traveler signal as synthetic. Replace them with the target game's real path and communication rules. Selecting a gate or signal only previews it; a separate action is required to cross or send.

This is an editable Web reference package. It does not include official Journey assets, a live co-op connection, game-engine scenes, or a tested engine export.
