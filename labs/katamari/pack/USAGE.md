# Use katamari-ui

This is a self-contained art-direction skill package for original game UI work.

1. Invoke the skill when a request calls for toybox collage and cosmic pop ui.
2. Read SKILL.md, visual-rules.md, tokens.json, and the relevant screen-pattern section.
3. Open assets/components/index.html locally to inspect editable fragments; its small selection controls update only specimen state.
4. Adapt the synthetic contract to the actual game state and write the three requested surfaces independently.

No external runtime, network request, or font download is required. System font stacks are used. The illustration is an original generated direction study, not source-game artwork. Keyword demand has not been validated. Component browser capture and independent implementation QA are pending.
