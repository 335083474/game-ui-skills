# Package use

Read SKILL.md, then open the references it names for the screen being designed. The package works from local files and system fonts; its specimen page can be opened directly in a browser without a build step or network access.

The generated atmosphere plate provides fog, silhouette, and material cues. The HTML specimens show a pause veil, chapter checkpoint selection, and a transient contextual prompt. Compose them into a requested screen using the target game's actual state and controls. The included data is synthetic and does not persist.

This is a reference Skill package and editable Web specimen set. It does not provide official LIMBO assets, a game engine scene, or an engine export.
