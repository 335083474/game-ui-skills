# LittleBigPlanet 3 craft UI reference

Use this reference when a requested interface should feel assembled from soft craft materials. It is an independent visual study, not an official asset pack or exact recreation.

Read [visual-rules.md](references/visual-rules.md), [tokens.json](references/tokens.json), and only the requested entries in [screen-patterns.md](references/screen-patterns.md). Use [reference-plate.png](references/images/reference-plate.png) as a crop or material cue; it contains no source-game characters.

The approved directions are sticker-book, costume-workbench, and level-pods. The editable [component specimens](assets/components/index.html) demonstrate small reusable parts; they are not finished screens. Compose the requested surface for the player's task and actual state. Keep felt pile, thread, buttons, and corrugated cardboard visibly distinct.

Treat each selection as a reversible preview until the player chooses an explicit apply action. Show selected, unavailable, and confirmed states in words as well as color. Use native buttons, visible keyboard focus, readable contrast, narrow-screen reflow, and reduced-motion behavior. The demo changes only its local preview; it does not persist game data.

The source boundary and art provenance are in [sources.md](references/sources.md) and [asset-map.json](references/asset-map.json). This package provides visual guidance and web specimens only; it has no engine export, official fonts, official characters, or verified search-demand data.
