# Use littlebigplanet-ui

Invoke this reference for original interfaces that need a warm, hand-assembled craft world: fuzzy felt, visible stitches, sewn patches, wooden buttons, and layered cardboard.

For a requested surface, read its pattern in references/screen-patterns.md and the matching state in references/demo-state.json. Inspect references/images/reference-plate.png and the editable fragments in assets/components/index.html with assets/components/theme.css. Compose a new screen from the fragments and actual game state; do not copy the component board as a finished page.

Use reversible selection followed by an explicit apply action. The specimens demonstrate local preview and confirmation only. The source game, its characters, and its UI assets are not included. Search demand is unknown; this is an experimental visual reference, not an engine-ready export.
