# Use mini-metro-ui

Provide the complete `mini-metro-ui` folder to an AI that can read local files and SVG images. Point it to `SKILL.md`, then ask for a specific player task and one or more of the screen patterns in `references/screen-patterns.md`.

The reference image and `assets/art/` contain original vector material made for this package. `assets/components/index.html` is an editable specimen board. Open it locally in a browser to inspect reusable parts and their local selection/preview behavior. Copy individual components into a new layout; it is not a ready-made screen.

For a useful request, specify the screen purpose, player actions, target viewport, required states, and content. Ask for keyboard and narrow-screen behavior. Save the generated implementation outside this package so the reference input stays intact.

The source page is linked in `references/sources.md`; it was not checked during this authoring pass and does not establish exact UI details. All sample values and names are invented. See the listed limitations before making fidelity, integration, licensing, or search-demand claims.
