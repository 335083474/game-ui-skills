# Source and asset provenance

## Primary reference

- EA’s approved Mirror’s Edge landing page: https://www.ea.com/en-ca/games/mirrors-edge
- That landing page currently groups Mirror’s Edge and Catalyst. Its separate original-game link opens EA’s product page: https://www.ea.com/en-ca/games/mirrors-edge/mirrors-edge
- The original product page names Mirror’s Edge, identifies EA as publisher and DICE as developer, describes an agile courier using rooftops, and lists a PC storefront date of 13 Jan 2009. The approved local plan fixes the design scope as the original 2008 game and excludes Catalyst. The listed PC date is later; this package does not describe it as a 2008 PC release.
- The source supports title and broad traversal context. It does not supply a UI manual or validate the design interpretation of white architecture and red route marks.

## Generated context artwork

- references/images/style-board.png is original generated architectural context art created on 2026-10-16. It shows an invented rooftop, city, and anonymous distant runner.
- The image is not official EA artwork, a copied game level, a screenshot, or a primary source.
- No official character image, logo, typography file, or UI asset is included.

## Scope limits

Route names, distances, objectives, demo key, and cue outcomes are invented. The browser prototype demonstrates DOM/CSS specimens only. It is not Catalyst, a recreation of the game HUD, a verified control map, or an engine export.
