# Mundaun UI reference

Use this self-contained package to create editable browser-game UI in a pencil-and-paper direction. Its art and component studies are original, not official game assets or a framework integration.

Read the [visual rules](references/visual-rules.md), [local tokens](assets/tokens.css), and [usage notes](USAGE.md). Open the [editable component specimens](assets/components/index.html) in a browser. The [direction artwork](assets/references/direction-board.svg) is original vector art, not a game screenshot.

The approved experiments are:

- **satchel:** varied object drawings in paper cells with counts kept at the edge.
- **journal:** one dated observation paired with a small landmark sketch.
- **trail-map:** layered contour marks, sparse route lines, and compact orientation metadata.

Keep the first-person playfield open during movement; place the full inventory, journal, and map behind explicit pause surfaces. Use semantic controls, keyboard focus, responsive layout, and local system font stacks. Read [sources and limits](references/sources.md) before treating a visual statement as canonical.
