# Sources and edition boundary

Checked 2026-10-16. The target is the 2017 original NieR:Automata UI direction. This package uses original demonstration data and local authored vector specimens; it redistributes no official screenshots, UI files, logos, music, characters, or extracted assets.

## Primary design source

- [PlatinumGames — UI Design in NieR:Automata](https://www.platinumgames.com/official-blog/article/9624), by UI and mecha designer Hisayoshi Kijima, dated 2017-08-25. It explicitly describes a systematic, sterile but beautiful direction; flat design; a faint grid; warm beige; limited color; score-line symbolism; and simple joystick/confirm/back guidance. The visual rules use these stated principles and add Web-specific spacing.
- [Steam — NieR:Automata](https://store.steampowered.com/app/524220/), official publisher listing for the 2017 release. It establishes the named game, developers, and date; the package's focus on the original UI direction follows the listing/version boundary.

## Interpretation limits

The official developer article is evidence for design intent, not a complete token sheet or implementation spec. CSS colors, grid spacing, demo chip values, and Web behavior here are author-created approximations. The local score-line SVG is an abstract original motif, not a copied in-game asset. No claim of exact game fidelity or affiliation is made.
