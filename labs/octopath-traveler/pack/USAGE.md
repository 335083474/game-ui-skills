# Package use

Read SKILL.md and the relevant screen pattern. Open assets/components/index.html to inspect the integrated battle stage, party strip, and equipment comparison. The specimen page is offline and uses its own local atmosphere image, CSS, and JavaScript.

All party names, equipment, turn order, and values in the fixture are synthetic. Replace them with the user's actual game data. Selecting a member or item changes a preview; equipment and battle actions require separate confirmation.

The package is a visual reference Skill and editable Web specimen set. It does not include official OCTOPATH TRAVELER characters, a working battle engine, persistence, or engine exports.
