# Use okami-ui

Invoke this package for original interfaces drawing on japanese ink-scroll action ui.

Read SKILL.md with visual-rules.md and the pattern for the requested surface. Inspect the editable specimen page in assets/components/index.html, then build a separate application composition using real product state.
