# Use ori-wisps-ui

Use for original ability configuration, shard loadout, and forest map surfaces drawing on the deep, hand-painted atmosphere associated with Ori and the Will of the Wisps.

Keep artwork original. The local reference uses an invented forest and spirit-moth form and is not a Blind Forest or Will of the Wisps screenshot. Bind stable IDs, prerequisites, slot replacement, and map states to a real state contract. The component page shows isolated editable fragments and does not persist game data.

No fonts or remote runtime assets are bundled. Component capture and independent screen implementation QA remain pending.
