# Use paper-mario-ui

Give an AI the complete paper-mario-ui folder and point it to SKILL.md. Request one of the authored patterns or describe a new player task, then specify viewport, controls, content, and required states.

The reference board and assets/art/ui-atlas.svg are original local artwork. assets/components/index.html is an editable, responsive parts board; copy and recompose useful pieces for a new screen. Its controls only change local preview state.

The official context page in references/sources.md was opened on 2026-10-16 for product identification. It does not verify the screen designs in this package. Sample names, counts, and states are fictional. Save generated work outside this package so the reference inputs remain unchanged.
