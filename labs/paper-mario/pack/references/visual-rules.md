# Visual rules

## Paper and stage grammar

Build with separate cut-paper planes, confident dark ink outlines, and short offset shadows. Let an edge, overlap, badge, or stage ribbon explain the hierarchy. The 2024 Switch direction is a clean paper-diorama study; use crisp layers rather than folded origami creases.

Use cream paper for reading surfaces, muted green-blue for scenery, and red or sun yellow only for selection, action, or category distinction. Keep body text on an opaque, quiet sheet. Avoid soft glass blur and generic floating-card dashboards.

## Interaction and state

A selected badge, item, or command needs a visible outline plus a word or symbol. Separate preview from equip/use/confirm. Keep capacity as discrete paper pips. Stage commands should identify both selected action and target; the audience meter is supporting feedback, not the primary action.

Use semantic buttons, keyboard order, visible focus, and at least 44px touch targets. Local specimen controls change presentation only; never imply that they changed a save or battle.

## Type and responsive layout

Use the system serif for short folio headings and a system sans for item names, controls, counts, and long copy. Do not bundle or fetch fonts. Reflow badge and item collections near 620px while preserving stage-command hierarchy and touch targets.

Honor reduced-motion preferences. Use a brief selection transition only when it clarifies a state change. Keep paper grain subtle enough that it never crosses small text.
