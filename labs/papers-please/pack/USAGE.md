# Use this reference package

Provide the complete `papers-please-ui` folder to your AI. Ask it to use the desk, document, stamp, and ledger rules to compose new screens. `assets/components/index.html` is a specimen board; it is not a finished inspection / handbook / accounting app.

Suggested request:

> Use the `papers-please-ui` reference package to build three linked Web screens for a fictional border checkpoint: document inspection, policy handbook, and end-of-day ledger. Keep the PC desk version's narrow document workspace and crisp pixel edges. Use synthetic travelers and rules, implement field comparison and stamp decisions, preserve state between views, and put the runnable result and browser evidence in a separate output folder.

Read only the matching pattern in `references/screen-patterns.md` for each requested view. Never use real personal data or copy the game's text, art, interface labels, or logo. Browser validation and finished screen layouts belong outside this frozen package.
