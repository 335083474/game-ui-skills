# Sable UI reference

Use this self-contained package to create editable browser-game UI in a clear-line desert direction. It supplies original vector specimens and visual rules, not official game assets or an engine integration.

Read the [visual rules](references/visual-rules.md), [local tokens](assets/tokens.css), and [usage notes](USAGE.md). Open the [editable component specimens](assets/components/index.html) in a browser. The [direction artwork](assets/references/direction-board.svg) is original vector art, not a screenshot.

The approved experiments are:

- **mask-collection:** original mask silhouettes with found, worn, or rumored state.
- **quest-journal:** one active entry with a slim index and a short route clue.
- **desert-map:** flat dune bands, light contour, a route trace, and one tracked destination.

Keep the landscape as the primary content during exploration. Use semantic controls, keyboard focus, responsive layout, and local system font stacks. Read [sources and limits](references/sources.md) before treating a visual statement as canonical.
