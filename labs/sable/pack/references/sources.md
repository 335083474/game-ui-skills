# Sources and interpretation

## Official source

- [Official Steam product page for Sable](https://store.steampowered.com/app/757310/)

The official listing describes a journey across vast deserts, calls out masks and other collectibles, and refers to the game's unique art style.

## Approved editorial scope

The approved implementation-plan row selects the clear-line family and experimental-art-direction suitability for the 2021 PC original. It describes thin outlines, little shading, and flat color as an editorial hypothesis, and approves mask-collection, quest-journal, and desert-map. The row states that this is an editorial database gap and makes no measured demand claim. This plan evidence is recorded here so the package remains self-contained.

## Original work in this package

The local [direction artwork](../assets/references/direction-board.svg), [component specimens](../assets/components/index.html), [token CSS](../assets/tokens.css), and [visual rules](visual-rules.md) were authored for this reference package. They do not reuse or trace store screenshots, game UI captures, official art, logos, or bundled game files. Typography uses local system-font stacks; no font files are bundled.

The clear-line label and screen patterns are editorial interpretations. The official source does not validate these specimens as canonical game UI. This package makes no measured search-demand claim and does not provide an engine-ready implementation.
