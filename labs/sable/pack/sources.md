# Sources and interpretation

## Official source

- [Official Steam product page for Sable](https://store.steampowered.com/app/757310/)
- [Approved classic UI implementation plan](../../research/classic-ui/gap-implementation-plan.json), row sable.

The official listing describes a journey across vast deserts, calls out masks and other collectibles, and refers to the game's unique art style. The plan selects clean-line and flat-color desert traits as an editorial hypothesis. The source does not specify exact interface anatomy.

## Original work in this package

The local [direction artwork](assets/references/direction-board.svg), [component specimens](assets/components/index.html), [token CSS](assets/tokens.css), and [visual rules](references/visual-rules.md) were authored for this reference package. They do not reuse or trace store screenshots, game UI captures, masks, official logos, or bundled game files. Typography uses local system-font stacks; no font files are bundled.

The clear-line label and screen patterns are design interpretations. The official source does not validate these specimens as canonical game UI. This package makes no measured search-demand claim and does not provide an engine-ready implementation.
