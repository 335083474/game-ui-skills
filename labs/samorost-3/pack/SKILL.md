# Samorost 3 naturalist UI reference

Use this reference when the requested interface should feel discovered in a miniature natural world. The art direction combines photographic moss, bark, and fungi with quiet storybook collage. It is an independent visual study, not a canonical recreation.

Read [visual-rules.md](references/visual-rules.md), [tokens.json](references/tokens.json), and the requested section of [screen-patterns.md](references/screen-patterns.md). Inspect the original [natural collage plate](references/images/reference-plate.png) for its moss, wood, mushrooms, and invented seed-pod traveler. It is not a source-game character.

The approved patterns are object-combination, pictorial-hints, and planet-chapters. The [component specimens](assets/components/index.html) are small interaction fragments, not finished screens. Let image, silhouette, sequence, and spatial cues carry meaning; use concise labels and accessible names where needed.

An object selection is a preview until the player chooses a clear combine or route action. Keep controls keyboard accessible, provide visible focus and text feedback, reflow for narrow viewports, and respect reduced motion. The specimens change only local page state.

The source scope and generated-art provenance are in [sources.md](references/sources.md) and [asset-map.json](references/asset-map.json). This package includes no canonical character or source-game art, engine scene, remote font, or measured search-demand evidence.
