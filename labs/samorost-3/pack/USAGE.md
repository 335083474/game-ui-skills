# Use samorost-3-ui

Invoke this reference for quiet, picture-led adventure UI made from miniature natural textures and small physical objects. Let a player infer relationships from shape and sequence, while keeping an accessible text equivalent for every pictorial control.

Read the requested screen pattern and its example state, then inspect the generated plate and editable specimen page in assets/components/index.html. The three samples teach object combination, a picture sequence, and planet selection as separate parts; compose a new surface for the actual player task.

Keep selections reversible until “Combine” or “Set route” is chosen. These are local web specimens only. Their invented object and planet names are examples; no canonical character art, engine export, or keyword-demand claim is included.
