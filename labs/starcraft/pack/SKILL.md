# StarCraft interface reference

Use this experimental package for original interfaces informed by **1998 original Terran console direction; not Remastered**. It is not a publisher asset pack, exact reconstruction, engine export, or verified gameplay implementation.

Read visual-rules.md, tokens.json, screen-patterns.md, and sources.md in references. Inspect the original style board, reusable vector atlas, and editable component specimens.

The approved screen IDs are command-console, unit-roster, mission-brief. Build separate responsive views with clearly labeled synthetic content. Keep runtime files local; no hosted fonts, images, or services are needed. Keep the battlefield central and open, with Terran telemetry above and the actual command console directly below.

The component page shows editable parts, not completed screens. Reuse only relevant pieces in your own composition.
