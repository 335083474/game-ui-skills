# Using the StarCraft UI reference package

Give your AI this complete package so it can use the local visual rules, original art, and screen contracts.

Example request:

> Use the starcraft-ui skill to create these related responsive Web views: command-console, unit-roster, mission-brief. Target 1998 original Terran console direction; not Remastered. Read the screen patterns, reuse the original local vector atlas, keep all values synthetic, and save generated screens outside this package.

Open assets/components/index.html for editable component specimens. It is a component reference page, not a finished screen. Compose the requested screens independently.

The official source in references/sources.md identifies the target product and edition. The package has no external runtime dependencies or official art.
