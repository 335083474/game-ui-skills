# Visual rules

A 1998-era Terran console: dark steel plates, compact telemetry, an original unit portrait, restrained amber and teal status lights, and commands anchored below an unobstructed battlefield.

## Reusable grammar

- Keep labels, values, and state names readable without relying on color alone.
- Use the local CSS tokens in assets/components/theme.css; adapt layout to the requested screen and viewport.
- Reuse original local vector art from assets/art/symbol-atlas.svg. Do not add hosted fonts, images, icon sets, or runtime services.
- The editable component page is a reference board, not a completed game screen. Compose requested views from its parts.
- All names, statistics, counts, costs, maps, and example outcomes are synthetic.

## Playfield and command console

Keep the central playfield open and largest. Place the actual command console at its lower edge. Use edge telemetry and a small minimap only when useful; do not spread controls into a dashboard. Put long roster, briefing, inventory, or quest material in a focused alternate state.

## Edition boundary

1998 original Terran console direction; not Remastered. See sources.md for the official identity reference and its limits.
