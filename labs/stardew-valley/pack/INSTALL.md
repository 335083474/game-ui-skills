# Stardew Valley UI · 使用说明

版本 1.0.0。非官方、参考驱动的温暖田园像素 Web 界面 Skill 包。

## 交给 AI 使用

保留整个 `stardew-valley-ui` 文件夹的相对目录。可放入所用 Agent 的 Skills 目录，或直接给能读取本地文件、查看图片、编写代码的 AI 提供 `SKILL.md` 路径。

示例任务：

> 使用本地 stardew-valley-ui Skill。先读 SKILL.md、视觉规则和 tokens，实际查看两张参考图、组件板和物品图集。用 HTML/CSS/JS 为我的农场游戏生成奖励、背包、商店三个可切换界面。三屏构图不同但材料统一。实现一次性领奖、消耗药水且生命有上限、用游戏金币购买并处理库存和余额不足。文字数值可编辑，资源本地加载。完成后截图并记录实际测试。

也可以只要求一个界面，或让 AI 适配已有 Web 项目。包中没有完成的奖励、背包、商店页面；`assets/components/index.html` 只展示独立组件与状态，后续 AI 需要自己组织页面及行为。

## 本地查看与复用

直接查看 `assets/components/index.html`，或通过项目已有的本地静态服务打开。HTML 引用同目录 `theme.css`；CSS 的字体和图集均为包内相对路径。复制组件时也复制字体、图集，或按项目目录更新相对路径。所有标题、数量和标签都可在 HTML 或应用状态中改。

入口 `SKILL.md` 指向视觉规则、三类布局模式、资产来源和验收标准。`assets/tokens.json` 保存配色、间距、边框、字号及固定图集坐标。`agents/openai.yaml` 为支持此格式的工具提供展示元数据。

## 边界

当前验证范围是 Web。未验证 Unity、Godot、Unreal 或 Figma；没有附带引擎场景、在线模型、真实支付或服务器。字体本地打包并附原 OFL；中文走系统字体回退。参考图和物品是 AI 生成的非官方视觉研究，不是游戏官方资产，也不构成特定商业用途的授权保证。包本身不调用 API；AI 使用及额外美术生成的能力和费用取决于所用环境。
