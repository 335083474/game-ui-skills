# Use tearaway-ui

Invoke this reference for original game UI built from folded, cut, and layered paper: visible score lines, raised tabs, papery shadows, and movable paper tokens.

Read the requested entry in references/screen-patterns.md and its synthetic state in references/demo-state.json. Inspect the generated plate at references/images/reference-plate.png and the editable pieces at assets/components/index.html with assets/components/theme.css. Compose a new surface for the actual game task; the specimen board is not a finished screen.

Keep paper geometry physical and legible. Previewing an outfit, collection piece, or route does not commit it; provide a separate pin or unfold action. This package is an offline web reference with original generated art, not a canonical Tearaway asset pack or engine export.
