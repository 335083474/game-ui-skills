# Terraria interface reference

Use this experimental package for original interfaces informed by **PC 1.4-era interface direction; no exact build claim**. It is not a publisher asset pack, exact reconstruction, engine export, or verified gameplay implementation.

Read visual-rules.md, tokens.json, screen-patterns.md, and sources.md in references. Inspect the original style board, reusable vector atlas, and editable component specimens.

The approved screen IDs are inventory, crafting, equipment. Build separate responsive views with clearly labeled synthetic content. Keep runtime files local; no hosted fonts, images, or services are needed. Keep the cell grid dense, the deep-blue bevel crisp, and equipment and maker recipes distinct.

The component page shows editable parts, not completed screens. Reuse only relevant pieces in your own composition.
