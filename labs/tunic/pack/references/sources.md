# Sources and interpretation

## Official source

- [Official Steam product page for TUNIC](https://store.steampowered.com/app/553420/)

The official listing describes TUNIC as an isometric action game and describes its reconstructed Instruction Manual as containing maps, tips, techniques, and illustrations.

## Approved editorial scope

The approved implementation-plan row selects miniature-isometric art direction for the 2022 PC original, with a specific limit to keep modeled-world and paper-manual studies separate. It approves exactly inventory, manual, and island-map. The row states this is an editorial database gap and makes no measured demand claim. This plan evidence is recorded here so the package remains self-contained.

## Original work in this package

The local [direction artwork](../assets/references/direction-board.svg), [component specimens](../assets/components/index.html), [token CSS](../assets/tokens.css), and [visual rules](visual-rules.md) were authored for this reference package. They do not reuse or trace store screenshots, manual pages, character art, official logos, or bundled game files. Typography uses local system-font stacks; no font files are bundled.

The miniature scene, item marks, glyphs, and component anatomy are editorial interpretations. The official source does not validate these specimens as canonical game UI. This package makes no measured search-demand claim and does not provide an engine-ready implementation.
