# Use this reference package

Pass the whole `undertale-ui` directory to your AI. It includes an SVG reference and editable command / list / dialogue primitives. `assets/components/index.html` is a small specimen board, not a ready-made battle, inventory, or conversation screen.

Suggested request:

> Use the `undertale-ui` reference package to build three connected Web screens for an original retro RPG: battle commands, item selection, and dialogue. Keep the 2015 original monochrome command-box hypothesis, invent all characters and copy, and implement select / confirm / cancel with keyboard and pointer. Keep the playfield quiet and text readable. Save the finished screens and browser evidence outside the package.

Read the requested pattern before composing it. The selected item is not consumed until confirm, and Back returns to the prior selection. No official characters, images, game text, music, font binaries, or game files are included.
