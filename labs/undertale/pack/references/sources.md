# Sources and limits

## Edition boundary

- [Undertale — official Steam product page](https://store.steampowered.com/app/391540/), checked 2026-10-16. The page credits tobyfox and lists the September 2015 release. This package follows the frozen research entry's **2015 original** boundary, not Deltarune.

The product page does not publish a UI style specification. The black field, white frame, heart cursor, and command patterns are an original interpretation. No official screenshots, sprites, soundtrack, text, or font files are included.

## Market and asset limits

All visible UI art is authored HTML / CSS / native SVG. The frozen research entry records a Pixel Graphics review rank; that is not a search rank or UI-asset demand. Generic pixel UI packs already exist according to the entry, while title-specific search metrics are unknown. Do not call this a validated SEO opportunity.
