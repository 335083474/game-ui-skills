# Warcraft III interface reference

Use this experimental package for original interfaces informed by **2002 Reign of Chaos Human console direction; not Reforged**. It is not a publisher asset pack, exact reconstruction, engine export, or verified gameplay implementation.

Read visual-rules.md, tokens.json, screen-patterns.md, and sources.md in references. Inspect the original style board, reusable vector atlas, and editable component specimens.

The approved screen IDs are command-console, hero-inventory, quest-log. Build separate responsive views with clearly labeled synthetic content. Keep runtime files local; no hosted fonts, images, or services are needed. Keep the Human battlefield central and the carved stone-and-wood command console directly below it; use blue-gold faction edging and parchment only for focused notes.

The component page shows editable parts, not completed screens. Reuse only relevant pieces in your own composition.
