# Use this reference skill

Give your AI the complete package so it can apply the tactical visual grammar, inspect local vector assets, and use the synthetic screen contracts.

Example request:

> Use the XCOM 2 UI reference skill for three connected screens: squad equipment, tactical orders, and research. Target the base 2016 edition without War of the Chosen. Keep the action budget visible, use the synthetic squad state in screen-patterns.md, and make movement, weapon selection, and research commitment work. Save implementation and screenshots outside this skill folder.

Open `assets/components/index.html` to see local CSS/HTML specimens. Copy the specific dossier, chance, command, and progress primitives into the generated screen; do not use the specimen page as a finished HUD.

The package includes original SVG marks only. All soldier names, percentages, costs, gear, and research durations are invented. There is no official screenshot, font, game asset, or engine export.
