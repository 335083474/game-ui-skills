# Use zelda-alttp-ui

Give an AI the complete zelda-alttp-ui folder and point it to SKILL.md. Request one of the authored patterns or describe a new player task, then specify viewport, item/room data, controls, and required states.

The reference board and assets/art/ui-atlas.svg are original local artwork. assets/components/index.html is an editable, responsive parts board; copy and recompose useful pieces for a new screen. Its controls only change local preview state.

The Nintendo manual link in references/sources.md was opened on 2026-10-16 to identify the linked game. It does not verify the screen designs in this package. Sample items, prices, rooms, and counts are fictional. Save generated work outside this package so the reference inputs remain unchanged.
