# Sources and asset boundaries

## Product and manual context

- [Nintendo Spain: The Legend of Zelda: A Link to the Past manual (PDF)](https://www.nintendo.com/es-es/games/oms/snes-classic/manuals/zelda/manual.pdf) is the official manual link selected by the approved plan. Opened on 2026-10-16 to confirm the linked game title.
- Fixed study target: 1991 Super Nintendo original direction. The approved plan fixes this scope. The manual is context, not evidence for the original component sketches or exact visual rules in this package.
- All interface geometry and visual rules here are original interpretation. No source-game screen was traced.

## Original package files

- references/images/reference-board.svg and assets/art/ui-atlas.svg are original SVG illustrations. They contain no extracted screenshots, logos, sprites, textures, or character designs.
- assets/components/index.html and assets/components/theme.css are editable local HTML/CSS specimens. Controls change local presentation state only.
- No external image, font, script, or runtime network request is required.

## Limits

This is an original art-direction study, not an official UI specification or engine export. Example item names, prices, room geometry, and counts are invented. Search volume and ranking are unknown.
